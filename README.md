## Welcome

Welcome to *One Day, Four Architectures* — a full-day, hands-on workshop where you will build and extend four different application architectures using C# and Azure.

This isn't a lecture. You're rolling with the crew. By the end of the day, you'll have built and extended real applications across four foundational architectural styles and have a practical framework for choosing the right architecture for the right job.

> *"Four builds. One day. No room for hesitation. Architecture is not a stylistic choice; it's a deliberate response to requirements."*

## Prerequisites

Before the workshop, please ensure the following are installed and verified:

- [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)
- [Docker Desktop](https://www.docker.com/products/docker-desktop)
- [Visual Studio 2022+](https://visualstudio.microsoft.com/) or [VS Code](https://code.visualstudio.com/) with C# Dev Kit
- EF Core CLI: `dotnet tool install --global dotnet-ef`
- Git
